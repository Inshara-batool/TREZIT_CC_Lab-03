Cloud Computing · Lab 03

GIT • COLLABORATION • DEPLOYMENT

From Local Repository to Live Website

This lab explores practical Git workflows for managing project history, handling collaboration challenges, recovering from mistakes, and publishing a website through GitHub Pages.

The focus is on understanding not only the commands, but also how Git manages changes across the working tree, staging area, local history, and remote repository.

What Was Practiced

01 / VERSION CONTROL

Repository & Commits

Initialized a local repository, tracked files, created commits, and inspected project history using Git commands.

02 / CHANGE MANAGEMENT

Stash & Restore

Used git stash to temporarily save uncommitted changes and git stash pop to restore them.

03 / RECOVERY

Reset & Revert

Explored the difference between moving a branch reference and creating a new commit that reverses earlier changes.

04 / DEPLOYMENT

GitHub Pages

Prepared a static HTML website and configured a GitHub repository for web publishing.

The Outcome

A practical understanding of Git-based change management, basic recovery workflows, and the process of taking a website from a local project to online deployment.
